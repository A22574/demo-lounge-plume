# Демо «Лаундж Plume» — лендинг для портфолио

Демонстрационный одностраничный сайт лаунджа (кальянная, вечернее место).
Собран как пример атмосферного дизайна для откликов на Kwork.

- Стек: чистый HTML + CSS + JS, сборка Vite
- Дизайн: тёмная «вечерняя» страница - сливовый фон, янтарный акцент, дымное свечение,
  кальянная карта с ценами, форма бронирования со штампом «Бронь принята»
- Полностью адаптивен

## Смотреть

Готовая версия лежит в папке `docs/` и публикуется через GitHub Pages:
https://a22574.github.io/demo-lounge-plume/

## Запуск локально

```bash
npm install
npm run dev     # http://localhost:7100
npm run build   # сборка в dist/, переложить в docs/ при обновлении
```

Контент вымышленный (Plume, Казань) - сайт сделан как демо-пример ниши.
